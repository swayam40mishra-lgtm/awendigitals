Owner's checklist

Before you publish.

This website is a static multi-page starter. Complete these setup steps so customers can reach the real business.

1. Configure contact details

Open assets/config.js and replace the WhatsApp placeholder with the dedicated business number using digits only, including country code (for India, 91 followed by the number). Add a business email if one is ready.

2. Review offers and policies

Before taking paid work, write down the exact ₹299 website scope, the ₹199 reel-editing deliverables, revision rules, realistic timelines, payment and handover process, and what post-launch support costs.

3. Replace demo work over time

All portfolio samples on this starter site are clearly labelled as concepts. Add real work only when completed and when you have permission to publish any client name, logo, assets or testimonial.

4. Verify brand/legal details

Check domain and social handle availability and relevant trademark/name conflicts before spending significantly or making registration claims. Don't publish a home address or unnecessary personal details.

Technical setup

  • Upload the folder contents to a static host.
  • Keep the relative folder structure intact.
  • Test all navigation links on mobile.
  • Test WhatsApp on Android, iPhone and desktop.
  • Check titles, metadata and contrast.
  • Confirm there are no placeholders or broken links.
  • Keep a backup of source files.

No backend or build step is required. Open index.html locally for a quick preview, or use a local static server for more realistic testing.
