# AWEN DIGITALS — Website source

A lightweight, responsive, nine-page static website for AWEN DIGITALS.

## Pages
- Home (`index.html`)
- Websites (`websites.html`)
- Reel Editing (`reel-editing.html`)
- Graphic Design (`graphic-design.html`)
- Packages (`packages.html`)
- Portfolio (`portfolio.html`)
- About & Founder (`about.html`)
- FAQs (`faqs.html`)
- Contact (`contact.html`)
- Launch checklist (`README.html`)

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a browser, or serve the folder using any static web server.
3. Keep the `assets/` directory alongside the HTML files.

## Required before launch
Open `assets/config.js` and replace:
- `REPLACE_WITH_BUSINESS_WHATSAPP_NUMBER` with the business WhatsApp number, digits only, including country code (India: 91 + number).
- Set `email` to the real business email if one is ready.

The contact form uses WhatsApp when a valid number is configured. Until then, it downloads a text file rather than pretending to send a message.
